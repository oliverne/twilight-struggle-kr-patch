# Phase 2 — 문자열 추출 & 번역 소스 구축

## 상태

- 상태: ⬜ 대기
- 선행 Phase: Phase 1 완료

## 목표

실제 사용되는 TextAsset에서 영문 문자열을 추출하고, 기존 블루칩 패치의 한글 번역을 현재 게임 버전에 맞춰 `translation/`의 소스 파일로 정리한다.

## 체크리스트

- [ ] 영문 문자열 추출 → `translation/` JSON
- [ ] 기존 패치에서 한글 번역 추출
- [ ] 현재 문자열과 기존 번역 자동 매칭
- [ ] 버전 차이 문장 수동 분류·번역
- [ ] 용어 통일표 `translation/glossary.md` 작성
- [ ] TMP 리치텍스트 태그 보존 규칙 수립
- [ ] 기타 TextAsset 사용 여부 확인

## 검증 기준

| 항목 | 성공 기준 |
|---|---|
| 문자열 추출 | 대상 TextAsset의 키·영문·메타데이터가 재현 가능하게 추출됨 |
| 번역 매칭 | 매칭 수와 미매칭 수를 산출할 수 있음 |
| 태그 보존 | `<color>`, `<font>`, `<br>`, `<indent>` 등이 원문과 번역에서 보존됨 |
| 재현성 | 원본 에셋에서 같은 명령으로 JSON을 재생성할 수 있음 |
