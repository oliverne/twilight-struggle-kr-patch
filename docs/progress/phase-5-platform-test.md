# Phase 5 — 플랫폼 적용 & 테스트

## 상태

- 상태: ⬜ 대기
- 선행 Phase: Phase 4 완료

## 목표

macOS·Windows 설치 스크립트를 완성하고, 코드 서명·게임 실행·멀티플레이·Steam 무결성 확인 이후 재설치까지 검증한다.

## 체크리스트

- [ ] macOS `scripts/install-mac.sh` 작성·검증
- [ ] macOS 애드혹 재서명 검증
- [ ] Windows `scripts/install-windows.ps1` 작성·검증
- [ ] 멀티플레이 동작 테스트
- [ ] Steam 무결성 확인 후 재설치 테스트
- [ ] 게임 버전·원본 해시 불일치 경고 확인

## 검증 기준

| 항목 | 성공 기준 |
|---|---|
| macOS | 설치 후 재서명된 게임이 실행됨 |
| Windows | 동일 에셋으로 게임이 실행됨 |
| 멀티플레이 | 패치 후 온라인 기능이 정상 동작함 |
| 복구 | 원본 복원 또는 Steam 검증 후 패치를 재적용할 수 있음 |
| 멱등성 | 설치 스크립트를 반복 실행해도 손상되지 않음 |
