## 배경

## 오탐 판정 (교정 제외 — 현상 유지)

- **"~것으로 간주/보이"** (28건): "인접한 것으로 간주됩니다" 등은 표준 한국어 표현. 스캐너 패턴에서 제외.
- **"~로 인해"** (다수): "거부권으로 인해" 등은 표준 한국어. 제외.
- **"~할 수 있다"** (155건): 카드 규칙서의 관용적 가능 표현 — 규칙 텍스트에 자연스러움. 제외.
- **"~적 N"** (105건): "업적 제목", "지정학적" 등 게임 용어/역사 용어 — 대부분 오탐. 제외.
- **"것입니다/것이다"** (40건): 규칙 정의문("~한 것이다")은 수용하되, 반복되는 항목만 2차에서 개별 처리.

## 3차: grammar-checker 맞춤법/문법 검사 (2026-08-12, scripts/scan_grammar.py)

3,125개 번역을 맞춤법·띄어쓰기·조사·구두점 규칙으로 스캔.
**검출 11건 전부 실제 오류 → 교정 완료 (재검증 0건).**

| 오류 | 건수 | 위치 | 교정 |
|---|---|---|---|
| 격전지**을** | 6 | runtime L582·L1440 (TMP 태그 사이) | 격전지**를** (받침 없는 '지'+을 → 를) |
| 비격전지**과** | 2 | runtime L582·L1440 | 비격전지**와** (받침 없는 '지'+과 → 와) |
| 승점**를** | 2 | TS_Cards Card_109Text, runtime L630 | 승점**을** (받침 있는 '점'+를 → 을) |
| 작전치**을** | 1 | runtime L567 | 작전치**를** |

- 교정: `scripts/polish_translations.py` G 규칙(조사 불일치, TMP 태그 허용 정규식) + L582/L1440은 `translation/polish-runtime.json`에 문단 교정본 추가(「~한 것이다」→「~한 것으로 본다」 3곳 포함).
- L582/L1440은 2차에서 교정안만 제시됐던 라인 — 이번에 실제 반영 완료.
- **오탐 처리**: 형태소 분석 없이 "이/가/은/는" 조사 검사는 단어 내부 음절(국가→국이, 플레이어→레이)과 구분 불가 → "을/를·와/과"만 검사. "효과·초과·부과·파라과이·우루과이·마나과·안와르" 등 흔한 단어는 블랙리스트로 제외. 따옴표 혼용·가운뎃점·던이/든·-ㄴ지/-는지 등 나머지 패턴은 게임 텍스트에서 검출 0건 또는 전부 정상 사용 확인.
